# 학습 페이지 메뉴 자동 반영

대상 프로젝트는 `C:/gen-ai-course/projects/full-stack/front-end`이다.

- `app` 아래에 `page.js` 페이지를 만들면 별도 요청이나 확인 없이 `app/components/AppMenu.js`에 해당 경로를 함께 등록한다. 사용자가 MenuApp이라고 부르더라도 실제 파일인 AppMenu를 수정한다.
- 기존 `chapters` 구조와 표시 순서를 따른다. 챕터 페이지는 챕터 항목으로, `Exam` 페이지는 해당 챕터의 `examples`에 중복 없이 추가한다.
- 중첩 페이지는 실제 URL과 일치하는 링크로 등록한다. 기존 메뉴 구조로 표현할 수 없으면 필요한 부분만 확장한다.
- 페이지 경로를 변경하거나 삭제하면 연결된 메뉴도 함께 갱신한다.
- 메뉴에서 챕터 전체 링크를 제공한다면 해당 챕터의 `page.js`가 존재하는지 확인하고, 없으면 기존 카드 형식의 챕터 페이지를 생성해 끊어진 링크를 방지한다.
- `ComponentA.js`, `ChildComponent.js` 같은 일반 자식 컴포넌트는 독립 경로가 아니므로 메뉴에 등록하거나 메뉴를 위해 페이지로 전환하지 않는다. 사용자가 명시적으로 독립 페이지를 요청하면 그때 페이지와 메뉴를 생성한다.
- 사용자가 메뉴 추가를 원하지 않는다고 명시하면 그 지시를 우선한다. 기존 사용자 변경을 보존하고 관련 파일만 수정한다.
- 변경한 페이지와 메뉴에 ESLint 검사를 수행하고, 결과와 추가한 경로를 간단히 보고한다.
